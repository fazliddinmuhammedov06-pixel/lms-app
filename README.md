# Friday Education

Профессиональная система управления обучением с геймификацией.

## 🎨 Дизайн-система

**Friday Education** — строгий и профессиональный дизайн:

- **Основной фон**: тёмно-синий (#0f172a - Navy)
- **Акцентный цвет**: оранжевый (#f97316)
- **Никаких скруглений** — острые углы (rounded-none, max rounded-sm)
- **Чёткие границы** вместо размытых теней
- **Плоский стиль** без псевдо-3D эффектов

## 🎯 Описание

LMS-приложение с тремя ролями пользователей:
- **Директор** — управление учителями, группами, обработка заявок на скидки
- **Учитель** — отметка посещаемости и начисление звёзд ученикам
- **Родитель/Ученик** — просмотр профиля, уровня, обмен звёзд на скидки

## 🛠 Технологический стек

- **Next.js 16.3.2** (App Router)
- **React 19.2.8**
- **TypeScript 5.9**
- **Tailwind CSS 4** — кастомная дизайн-система
- **Prisma ORM 5.22** — работа с базой данных
- **SQLite** — база данных (dev.db)
- **NextAuth.js** — авторизация (планируется)
- **Web Push API** — браузерные уведомления (планируется)

## 🗄 Модель данных

### Основные сущности

- **User** — пользователи системы (email, роль, пароль)
- **Teacher** — преподаватели (связаны с User)
- **Parent** — родители (связаны с User)
- **Student** — ученики (привязаны к Parent и Group)
- **Group** — учебные группы
- **Lesson** — занятия в расписании
- **AttendanceRecord** — записи посещаемости
- **StarTransaction** — история начислений/списаний звёзд
- **DiscountRequest** — заявки на скидки
- **PushSubscription** — подписки на push-уведомления

### Роли пользователей

```typescript
enum Role {
  DIRECTOR  // Директор
  TEACHER   // Учитель
  PARENT    // Родитель
}
```

### Статусы посещаемости

```typescript
enum AttendanceStatus {
  PRESENT   // Присутствовал
  ABSENT    // Отсутствовал
  LATE      // Опоздал
}
```

### Статусы заявок на скидку

```typescript
enum DiscountRequestStatus {
  PENDING   // Ожидает рассмотрения
  APPROVED  // Одобрена
  REJECTED  // Отклонена
  USED      // Использована
}
```

## 🎮 Система уровней

Уровень ученика рассчитывается по **общему количеству заработанных звёзд** (не по текущему балансу):

| Уровень | Название  | Минимум звёзд |
|---------|-----------|---------------|
| 1       | Новичок   | 0             |
| 2       | Ученик    | 100           |
| 3       | Знаток    | 250           |
| 4       | Мастер    | 500           |
| 5       | Эксперт   | 1000+         |

### Логика расчёта

```typescript
// lib/levels.ts
import { getStudentLevel } from '@/lib/levels';

const totalStars = 850;      // Всего заработано
const currentBalance = 320;  // Текущий баланс (после трат)

const level = getStudentLevel(totalStars, currentBalance);
// { level: 4, levelName: 'Мастер', totalStars: 850, ... }
```

## 🏆 Магазин наград

Ученики могут обменивать звёзды на скидки:

- **Скидка 5%** — 250 звёзд
- **Скидка 10%** — 450 звёзд

После обмена создаётся `DiscountRequest` со статусом `PENDING`, который должен одобрить директор.

## 📱 Функциональность по ролям

### Директор (`/director`)

- ✅ Сводка посещаемости за сегодня (PRESENT/ABSENT/LATE)
- ✅ Список заявок на скидку с кнопками "Одобрить"/"Отклонить"
- ✅ Список всех учителей с их группами и расписанием
- ⏳ Server Actions для обработки заявок

### Учитель (`/teacher`)

- ✅ Селектор группы и занятия
- ✅ Список учеников (отсортирован по totalStars)
- ✅ Кнопки посещаемости (Был/Пропустил/Опоздал)
- ✅ Кнопки начисления звёзд (+5, +10)
- ⏳ Server Actions для сохранения данных
- ⏳ Отправка push-уведомлений родителю при пропуске

### Ученик/Родитель (`/student`)

- ✅ Переключатель между детьми (если несколько)
- ✅ Карточка с текущим уровнем и балансом
- ✅ Прогресс-бар до следующего уровня
- ✅ Магазин наград (обмен звёзд на скидки)
- ✅ Список последних пропусков
- ⏳ Запрос разрешения на push-уведомления
- ⏳ Service Worker для получения уведомлений

## 📝 Примеры использования типов

```typescript
import { StudentWithStars, getStudentLevel } from '@/types';

// Получить ученика с транзакциями
const student = await prisma.student.findUnique({
  where: { id: 'student_id' },
  include: { starTransactions: true }
});

// Рассчитать общее количество звёзд
const totalStars = student.starTransactions
  .filter(t => t.amount > 0)
  .reduce((sum, t) => sum + t.amount, 0);

// Получить информацию об уровне
const level = getStudentLevel(totalStars, student.stars);
console.log(`${level.levelName} (${level.progressPercent}% до следующего уровня)`);
```
